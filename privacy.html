Effective date: 2026-11-17
YouTube API Data Summary

This research tool uses YouTube API Services to access public, non-authorized metadata for academic and public-policy research. Google's privacy practices are described in the Google Privacy Policy. YouTube API data are stored only as necessary for the research workflow and are refreshed or deleted in accordance with applicable YouTube API Services policies. Limited non-authorized API data are not retained indefinitely.

1. Who operates this API client

The IMMS Research Data Collector is operated for non-commercial academic and public-policy research by researchers at the Institute for Migration and Multicultural Studies, Busan University of Foreign Studies, Republic of Korea.

The API client itself is an internal research tool. This public page is provided for transparency and YouTube API compliance documentation.

2. Use of YouTube API Services

The API client uses YouTube API Services, currently including the YouTube Data API v3, to access public, non-authorized YouTube metadata for academic and public-policy research.

Use of the API client is subject to the YouTube Terms of Service and the YouTube API Services Terms of Service .

Google's privacy practices are described in the Google Privacy Policy .

3. Information accessed through YouTube API Services

The research tool may access public API data including:

  • YouTube video IDs
  • video titles and descriptions
  • channel IDs
  • publication dates
  • video duration
  • public availability and upload-status information
  • caption-availability flags
  • region-restriction metadata when returned by the API
  • age-restriction metadata when returned by the API

4. Information we do not collect

The current API client does not:

  • require YouTube user login or OAuth authorization;
  • request, collect, proxy, or store YouTube usernames or passwords;
  • collect individual viewing histories;
  • collect subscriptions;
  • collect private playlists or private videos;
  • collect YouTube comments in the current research workflow;
  • perform advertising, marketing, or audience profiling;
  • sell YouTube API data.

5. Purpose of processing

Public YouTube metadata are processed solely for non-commercial academic and public-policy research concerning international-marriage brokerage advertising and related online content.

The research activities include identifying and documenting candidate content, validating research corpora, observing current content availability, and supporting reproducible content-analysis workflows.

The research project does not use YouTube API data to infer sensitive personal characteristics such as race, ethnicity, nationality, or age from an individual's appearance, voice, or name.

6. Storage and retention of YouTube API data

YouTube API data are stored only as necessary for the approved research workflow.

YouTube API data are handled in accordance with the storage, refresh, and deletion requirements of the YouTube API Services Developer Policies.

Limited non-authorized API data are not intended to be retained indefinitely.

Where applicable, stored non-authorized API data are deleted or refreshed within the period required by YouTube API Services policies, including the applicable 30-calendar-day temporary-storage limit.

Research-generated records are managed separately from YouTube-provided API data and are identified as research-generated material.

7. Sharing and disclosure

YouTube API data are not sold, licensed for advertising, or provided to data brokers.

Access to API data is limited to researchers who are authorized to participate in the documented research project and who require access for the approved research purpose.

Aggregate research findings may be reported in academic publications and public-policy reports.

The research team seeks to avoid unnecessary disclosure of personal contact information or other identifying information in publications.

8. Security

The research team applies reasonable administrative and technical safeguards designed to protect API data and research data against unauthorized access, use, alteration, or disclosure.

Research data are stored outside public source-code repositories, and access is restricted to authorized research personnel.

API credentials are not published in source code or on this website.

9. User authorization and revocation

The current version of the API client does not request OAuth authorization and does not access Authorized Data tied to an individual user's YouTube account.

Accordingly, the current client does not store YouTube user OAuth tokens.

If a future version of the client requests user authorization or accesses Authorized Data, this Privacy Policy and the client workflow will be updated before such functionality is used, including applicable consent, revocation, and deletion procedures.

10. Data deletion or correction requests

Questions or requests concerning information stored by this research tool may be submitted using the contact information below.

Where applicable, the research team will review such requests in accordance with relevant law, institutional research requirements, and YouTube API Services policies.

Deleting information stored by this research tool does not delete information stored by YouTube.

Requests concerning removal of content from YouTube itself must be handled through YouTube's own services and procedures.

11. Changes to this Privacy Policy

This Privacy Policy may be updated if the API client's functionality, research use, or data practices change.

Material changes will be reflected on this page before the changed data practice is introduced.
