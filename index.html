Research documentation page.
This page documents an internal, non-commercial academic research tool. It is not a public-facing YouTube service and is not the official website of Busan University of Foreign Studies.

About the research

The IMMS Research Data Collector supports non-commercial academic and public-policy research on publicly available online content related to international-marriage brokerage advertising in South Korea.

The research program includes a 2026 academic study and a broader longitudinal study covering content published from 2020 through 2026.

The research focuses on advertising structures, information provision, promotional practices, and representational patterns in publicly available content rather than on profiling individual people appearing in videos.

Use of YouTube API Services

The research tool uses the YouTube Data API v3 to access public, non-authorized metadata for research purposes.

The current implementation uses public metadata endpoints such as videos.list and does not require YouTube user login or OAuth authorization.

The research tool may process public metadata including:

  • YouTube video IDs
  • video titles and descriptions
  • channel IDs
  • publication dates
  • video duration
  • public availability and upload-status information
  • caption-availability flags
  • region-restriction metadata when returned by the API
  • age-restriction metadata when returned by the API

The current research workflow does not collect YouTube login credentials, individual viewing histories, subscriptions, private playlists, or other private user-account information.

Research-only access

The API client is an internal command-line research tool used only by authorized researchers.

It is not offered as a public application, commercial product, video playback service, advertising service, recommendation service, or user-profiling service.

Data use and safeguards

  • YouTube API data are used only for documented academic and public-policy research purposes.
  • Research data are not sold or used for advertising.
  • Access to research data is restricted to authorized researchers.
  • The research project does not infer sensitive personal traits such as race, ethnicity, nationality, or age from appearance, voice, or names.
  • YouTube API data are stored, refreshed, or deleted in accordance with applicable YouTube API Services policies.

Terms of Use

Authorized users of this API client must use it only for the approved research purposes.

By using this API client, authorized users are also required to comply with the YouTube Terms of Service, the YouTube API Services Terms of Service , and the YouTube API Services Developer Policies .

The client does not authorize researchers to circumvent authentication requirements, age restrictions, geographic restrictions, DRM, or other technical access controls.
