IMMS Research Data Collector

Effective date: 2026-11-17

1. Purpose

The IMMS Research Data Collector is an internal, non-commercial academic research tool operated by researchers at the Institute for Migration and Multicultural Studies, Busan University of Foreign Studies, Republic of Korea.

The tool is used solely for approved academic and public-policy research.

2. Authorized users

Access to the API client is limited to researchers who are authorized to participate in the relevant research project.

The API client is not offered as a public application, commercial product, or general consumer service.

3. YouTube API Services

The API client uses YouTube API Services, including the YouTube Data API v3.

Authorized users must comply with the YouTube Terms of Service , the YouTube API Services Terms of Service , and the YouTube API Services Developer Policies .

4. Permitted use

The API client may be used only for documented academic and public-policy research purposes.

Users must not use the API client to:

  • circumvent authentication requirements or access controls;
  • bypass age restrictions or geographic restrictions;
  • circumvent DRM or other technical protection measures;
  • manipulate YouTube views, likes, subscriptions, comments, or other engagement metrics;
  • collect YouTube API data for advertising, commercial profiling, or data-broker activities;
  • redistribute YouTube content through a public-facing service;
  • use the client for purposes outside the approved research scope.

5. Research data

Research data obtained or generated through the API client must be handled in accordance with the project's approved research protocol, privacy policy, data-management plan, institutional requirements, and applicable YouTube API Services policies.

Access to research data is restricted to authorized research personnel.

6. Privacy

Use of the API client is subject to the IMMS Research Data Collector Privacy Policy .

7. No public media service

The IMMS Research Data Collector does not operate a public YouTube video player, video-hosting service, recommendation service, or media distribution platform.

The current implementation uses YouTube API Services for research-related public metadata processing.

8. Compliance and access restrictions

Use of this tool does not authorize users to access content that is private, removed, age-restricted, region-restricted, or otherwise unavailable through permitted access methods.

Users must not use credentials, cookies, VPNs, proxies, geo-spoofing, or other methods to bypass YouTube access controls for research acquisition.

9. Changes to these Terms

These Terms of Use may be updated when the API client's functionality, research scope, institutional requirements, or applicable platform policies change.

Material changes will be reflected on this page before the changed functionality or research practice is introduced.
